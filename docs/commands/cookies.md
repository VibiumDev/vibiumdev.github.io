---
title: vibium cookies
---

Manage browser cookies.

## Synopsis

```
vibium cookies [name] [value] [flags]
vibium cookies [command]
```

## Subcommands

### vibium cookies clear

Clear all cookies.

```
vibium cookies clear [flags]
```

```sh
vibium cookies clear
# Delete all cookies
```

## Examples

```sh
vibium cookies
# List all cookies

vibium cookies "session" "abc123"
# Set a cookie with name and value
```
