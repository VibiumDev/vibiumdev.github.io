Tap a touchscreen at coordinates.

## Synopsis

> **Nightly only.** This command is in the nightly builds but not yet in the latest npm release. See [What's in Nightly](../nightly.md).

```
vibium tap [x] [y] [flags]
```

## Examples

```sh
vibium tap 100 200
# Tap at (100, 200)
```
